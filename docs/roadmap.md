## 원칙
- `experiments/` = 버리는 실험 코드 (개념을 눈으로 보기). `src/` = 진짜 서버 (제출물)
- 단계마다 **끝 조건**을 먼저 정하고, 끝 조건은 **명령 한 줄로 확인할 수 있게** 만든다 (`tests/`)
- 동시성 방식: **epoll** 기반. 마지막에 하이브리드(epoll + 코어 수만큼 스레드)
- **시간이 모자라면 기능을 줄인다. 이해는 줄이지 않는다.** (AI에게 구현을 맡기는 건 누구나 한다. 검증하고 책임지는 게 내 역할)
- 단계마다 넘어가는 조건 (4개 다 해야 다음 단계):
  1. 통과 기준을 **내가 먼저** 말로 쓴다
  2. 테스트 결과를 예측하고 **내가 판정**한다
  3. 핵심 함수마다 **입력 → 출력, 왜 이렇게 했나**를 설명한다
  4. **이 코드가 틀릴 수 있는 곳 하나**를 찾는다
